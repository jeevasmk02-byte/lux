LUX BIRTHDAY WEBSITE — EXPANDED EDITION

RUN THE WEBSITE
1. Extract lux_birthday_website.zip.
2. Open the folder in VS Code.
3. Open index.html in a browser, or use VS Code Live Server.

TWO SONG PLAYLIST (ALREADY ADDED)
- assets/lux_song_1.mp3
- assets/lux_song_2.mp3
Press "OPEN YOUR SURPRISE" or the music button to start.
Song 2 automatically plays after Song 1. The music button pauses/resumes.
Browsers require a click before audio can play.

ADD YOUR CAPCUT VIDEO LATER
1. Export your CapCut edit as an MP4.
2. Rename it exactly: lux-birthday-video.mp4
3. Put it beside index.html in the main folder (not inside assets).
4. Refresh the website.
